Job Scraper Settings

Connect your Airtable base to start saving job postings.

Setup Guide
  1. Go to airtable.com/create/tokens and create a new token. Give it the data.records:write scope and access to your base.
  2. Find your Base ID in the Airtable URL: airtable.com/appXXXXX/... — it starts with app.
  3. In your Airtable base, create two tables with these exact column names (case-sensitive).
    "Save for later" table
    For jobs you want to bookmark but aren't ready to apply to yet.
    Column Type
    Job TitleSingle line text
    CompanySingle line text
    LocationSingle line text
    Salary RangeSingle line text
    Job DescriptionLong text (Markdown)
    URLURL
    "Add to applications" table
    For jobs you plan to apply to right away.
    Column Type
    Role or Job IDSingle line text
    EmployerSingle line text
    LocationSingle select — Remote, Seattle, NYC, Remote-first, Bellevue, Other/Unknown
    Salary RangeSingle line text
    Job DescriptionLong text (Markdown)
    URLURL
  4. Enter your credentials below and click Test Connection to verify everything works.
